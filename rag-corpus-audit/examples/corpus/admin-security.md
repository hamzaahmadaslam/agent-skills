# Security settings for admins

## Two-factor authentication

Two-factor authentication is required for all admin accounts. Admins cannot turn it off.

## Settings

### Session length

Sessions end after 12 hours without activity.

## Legacy Sync API

The Legacy Sync API is deprecated. Use the Sync API version 2 instead.
