# Release notes

## Desktop app 4.2

As of January 2024, the latest desktop app is 4.2. Version 5 will be released in March 2025 with a new sync engine.

## Desktop app 4.1

- The folder picker remembers the last folder you opened.
- Files with names longer than 200 characters now upload instead of stopping the queue.
- The app shows how many files are waiting to upload in the menu bar icon.
- Pausing sync from the menu now also pauses uploads that already started.
- The Settings window opens on the tab you used last.
- Photos uploaded from the camera roll keep their original creation date.
- The app no longer asks for the account password again after a restart.
- Conflict copies now include the device name, for example "report (laptop).docx".
- Large files resume from the last finished part after a lost connection.
- The Recycle list sorts by deletion date, newest first.
- The installer checks for 2 GB of free disk space before it starts.
- Sign-in accepts passwords with spaces at the start or end.
- The app writes fewer log lines when nothing changes.
- Selecting a folder that is already in sync shows a message instead of an error.
- Keyboard shortcuts work in the file list: arrows to move, Enter to open, Delete to remove.
- The upload speed limit accepts values from 50 KB/s to 100 MB/s.
- Proxy settings are read from the operating system unless you set them in the app.
- Renaming a folder on one device renames it on the others instead of copying it.
- The app starts faster on computers with more than 100,000 synced files.
- The sync status icon shows a warning when the account is almost full.
- Deleted folders go to Recycle as one item with their files inside.
- The Help menu opens the support page in the language of the app.
- Uploading a file that is still being written waits until the file is closed.
- Shared folders show the owner's name in the file list.
- The app asks before it deletes more than 1,000 files at once.
- Error messages include a code that support can look up.
- Moving a file between two synced folders no longer uploads it twice.
- The first sync after installing shows progress per folder.
- Time stamps in the activity list use the computer's time zone.
- The app stops syncing a folder whose disk is disconnected and resumes when it returns.
