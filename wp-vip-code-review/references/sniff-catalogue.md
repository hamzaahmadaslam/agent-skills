# VIP sniff catalogue

Read this when a PHPCS message comes from `WordPressVIPMinimum.*`, or from a WordPressCS or PHPCS sniff that the VIP
rulesets include, and you need what it catches, why VIP cares and what the fix is. Types are the ones each sniff
sets; `WordPress-VIP-Go` changes some of them (see `severity-levels.md`). Sources are the VIPCS 3.1.0 and
WordPressCS 3.4.1 source files, checked on 2026-09-26, plus the VIP pages named in the rows.

VIPCS sniff files live under
[WordPressVIPMinimum/Sniffs](https://github.com/Automattic/VIP-Coding-Standards/tree/3.1.0/WordPressVIPMinimum/Sniffs);
each row links its own file.

## Functions.RestrictedFunctions

Codes are `WordPressVIPMinimum.Functions.RestrictedFunctions.<group>_<function>`. Every row comes from
[RestrictedFunctionsSniff.php](https://github.com/Automattic/VIP-Coding-Standards/blob/3.1.0/WordPressVIPMinimum/Sniffs/Functions/RestrictedFunctionsSniff.php);
VIP pages that explain a row are linked in it.
